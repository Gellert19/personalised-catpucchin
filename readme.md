# personalised-catpucchin

 This is a catpucchin theme for a mobile discord client that I decided to modify in an attempt to fix a bug where revenge wrongly registered what type of theme it was i.e. registering `mocha` as a light mode theme and along the way I decided to modify latte as the text was too hard to read. Eventualy I decided to add a custom font as well.  

 This is my first time doing anything like this so with no clue on how to actually credit anything I just decided to add a section below with the sources for the themes and font.

## Sources

 Bunny/Vendetta/Revenge theme docs: [Theme Docs](https://vendetta-themes.gitbook.io/wiki)  

 Catpucchin theme: [Catpuchin Vendetta](https://github.com/catppuccin/vendetta)  

 Iosevka font: [Iosevka](https://github.com/be5invis/Iosevka)
